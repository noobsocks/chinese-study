# 汉 HÀN — 중국어 학습 앱

노트 단어 93개로 만든 **간격 반복(SRS) 학습 앱**.
아이폰 홈 화면에 "앱처럼" 설치해서 씁니다. (앱스토어·개발자 계정 불필요)

---

## 📚 학습 모드 (홈에서 선택)

| 모드 | 내용 | 채점 |
|------|------|------|
| **오늘의 학습** | 뜻·한자 4지선다 · 하루 20문제 목표 | 자동 |
| **한자 쓰기** | 획순 애니메이션 보고 손가락으로 따라쓰기 | 자동(획순) |
| **듣기** | 소리 듣고 맞는 한자 고르기 | 자동 |
| **말하기** | 발음(TTS) 듣고 따라 말하기 | 셀프 체크 |
| **복습** | 틀렸거나 아직 약한 단어만 모아서 | 자동 |

> ⚠️ **말하기 솔직한 한계**: 아이폰 사파리는 음성 인식 자동 채점을 지원하지 않아요.
> 그래서 "발음 듣고 따라 말하기(셀프 체크)"로 만들었고, 자동 채점이 필요한 **듣기** 모드를 따로 넣었어요.

맞히면 별(★)이 오르고 다음 복습 간격이 길어져요. 틀리면 별이 초기화되고 자주 다시 나와요.

## 🚀 1단계 — GitHub에 올리기 (웹에서만, 5분)

1. [github.com](https://github.com) 로그인 → 우측 상단 **`+`** → **New repository**
2. 이름 입력 (예: `han-study`) → **Public** → **Create repository**
3. **"uploading an existing file"** 클릭
4. 이 폴더의 **파일 8개 전부 드래그** → 아래 **Commit changes**

## 🌐 2단계 — 웹주소 켜기 (GitHub Pages)

1. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
2. **Source** → `Deploy from a branch` → **`main`** / **`/(root)`** → **Save**
3. 1분 뒤 새로고침 → 주소 생성:
   `https://내아이디.github.io/han-study/`  ← **앱 주소**

## 📱 3단계 — 아이폰에 설치

1. 아이폰 **Safari**로 위 주소 열기 (⚠️ 크롬 말고 사파리)
2. 아래 **공유 버튼**(⬆️) → **홈 화면에 추가**
3. `汉` 아이콘 생김 → 전체화면 앱처럼 실행 (오프라인 OK)

## 📅 학습 플랜 (커리큘럼)

홈 상단 배너에서 **7 / 14 / 30일 과정**을 선택하면, 전체 단어를 날짜별로 자동 배분해요.
- 7일 = 하루 약 13단어 / 14일 = 약 7단어 / 30일 = 약 3단어
- '오늘의 학습'은 그날까지 오픈된 단어 위주로 나와요
- 배너를 누르면 날짜별 학습 계획을 볼 수 있어요 (언제든 변경 가능)

## ➕ 단어 추가 (코드 편집 불필요)

**앱 안에서**: 아래 탭 **[단어]** → 한자 · 병음 · 뜻 입력 → **단어 추가**
- 추가한 단어는 모든 모드(학습·듣기·말하기·복습)에 즉시 반영
- 병음은 발음기호(ā á ǎ à)로 쓰면 성조 색이 자동 적용
- 삭제도 [단어] 탭에서 ✕ 버튼으로

**쓰기 모드**: 새 한자의 획순 데이터는 인터넷 연결 시 자동으로 받아와요.
오프라인이면 기본 133자만 쓰기 연습이 되고, 새 글자는 온라인에서 한 번 받아두면 이후 오프라인에서도 됩니다.

**대량 추가**(개발자용): `index.html`의 `const VOCAB=[` 에 `["한자","성조병음","뜻"],` 형식으로 직접 추가도 가능.
